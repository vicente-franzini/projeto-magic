# Projeto Final - Programação Orientada a Objetos

Nesse repositório está o projeto final da matéria de Programação Orientada a Objetos do grupo formado por Vicente Franzini, Felipe Sanches, Lucas Inácio e Vitor Gabriel.

## Sobre o projeto

Esse projeto é um simples CRUD, feito com a arquitetura Model-View-Controller, em C#.
Ele tem como finalidade armazenar cartas do jogo Magic the Gathering. Nele, você pode ter um de três cargos, detalhados abaixo:

> Administrador
O administrador tem como propósito criar novas cartas para serem armazenadas.

> Vendedor
O vendedor tem como propósito selecionar cartas adicionadas ao sistema pelo Administrador à venda.

> Comprador
O comprador pode comprar uma das cartas colocadas à venda pelo Vendedor.

## Modo de funcionamento

Como mencionado acima, o código é feito com a arquitetura MVC, sendo que o CRUD armazena os dados em três arquivos separados, na área de trabalho do usuário.
